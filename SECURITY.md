# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please send an email to Vasilis Tsiamouras via `btsiamouras@gmail.com`. All security vulnerabilities will be promptly addressed.

Please include:
- A description of the issue and potential impact
- Detailed steps to reproduce or a proof of concept
- Any potential remediations or workarounds

Please do not report security issues via public GitHub issues.
